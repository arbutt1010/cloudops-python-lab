# 📊 Project: Student Grade Manager

Your **first project**! It combines everything from week01:
**variables, strings, numbers, lists, dictionaries, loops, and conditions.**

You will build a small program that takes a class of students and their
scores, works out each student's grade, and prints a clean report with
some class statistics.

---

## 🎯 What the finished program should print

Something like this (your numbers will match the data in the file):

```
===== CLASS REPORT =====
Abdul    : 91  -> Grade A
Sara     : 84  -> Grade B
Ali      : 72  -> Grade C
Bilal    : 55  -> Grade F
Amna     : 68  -> Grade F

------ STATISTICS ------
Class average : 74.0
Highest score : 91 (Abdul)
Lowest score  : 55 (Bilal)
Students passed: 3 out of 5
```

---

## 🗂️ Files in this folder

- **`grade_manager.py`** ← YOU write your code here (it has step-by-step TODOs)
- **`solution.py`** ← a complete working version. **Only open this after you try!**

## ▶️ How to run

```
python grade_manager.py
```

Run it often as you go — build it one step at a time, not all at once.

## 🧩 Which week01 skill each step uses

| Step | Skill you'll practice |
|------|-----------------------|
| 1 | **dictionaries** — store students & scores |
| 2 | **loops** — go through each student |
| 3 | **conditions** — turn a score into a grade (A/B/C/F) |
| 4 | **strings (f-strings)** — print a neat report line |
| 5 | **numbers + loops** — average, highest, lowest, pass count |
